# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

- Il linguaggio usato in questo progetto è Python.

## Stile del codice

- Nomi (variabili, funzioni, file) tutti minuscoli, in italiano, con il trattino basso `_` come separatore.
- Nomi esplicativi ma brevi: massimo 2-3 termini separati da `_` (es. `calcola_totale`, `lista_task_completati`).
- Ogni funzione deve avere un commento iniziale che descrive cosa fa e cosa restituisce.
- Nel corpo del codice inserire alcuni commenti esplicativi nei punti meno immediati.
